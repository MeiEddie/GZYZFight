# 一中快打

广州市第一中学的校园同人格斗小游戏。纯 Canvas 实现，打开网页就能玩。

15 名角色分布在 10 列 × 4 行的学号座位上，支持双人对战与人机对战。角色由 AI 生成的动作帧和真人照片头像组合而成，背景是校园实拍，BGM 是校歌《奉献美好给未来》。

## 玩法

- **双人对战**：同一台电脑，1P 与 2P 各选一名角色开打。
- **人机对战**：1P 选好角色后，CPU 自动摇人应战。
- **胜负**：99 秒内把对方血量打空即获胜；时间到则剩余血量多的一方获胜。
- **战斗**：靠近后攻击，命中会掉血并产生连击；防御可减伤，跳跃能躲开攻击。
- 每个角色有速度、均衡、力量、防御四种体型，手感与伤害各不相同。

## 身体素材与角色

身体底模只有四个，命名只描述形态、不指向任何人物：

| id | 形态 | 对应类型 |
| --- | --- | --- |
| `slim` | 偏瘦 | 速度型 |
| `normal` | 匀称 | 均衡型 |
| `heavy` | 偏胖 | 力量型 |
| `stout` | 壮实 | 防御型 |

底模本身不带名字、班级、数值或头像。一个角色 = 底模（`slim`/`normal`/`heavy`/`stout`）
+ 头像（`assets/贴图/<学号>.webp`）+ `src/data/roster.js` 里的身份信息。
所以同一个人换个 `tag` 就换身体，名字和头像都不用动；想加新同学只改 `roster.js`。

类型到体型的映射在 `roster.js` 的 `TYPE_BODY`，头部贴图坐标在 `src/data/heads.js`（按体型 id 索引）。

## 操作

| 动作 | 1P | 2P |
| --- | --- | --- |
| 左右移动 | `A` / `D` | `←` / `→` |
| 跳跃 | `W` | `↑` |
| 攻击 | `J` | `Enter`（或小键盘 1 / 句号） |
| 防御 | `K` | 右 `Shift`（或小键盘 2 / 逗号） |

菜单用 `W` / `S` 选择、`Enter` 确认；`M` 静音；战斗中 `Esc` 或 `P` 暂停。

## 加载与素材

启动加载条按「真实字节」加权，分成下载（0→90%）与解码（90→100%）两个阶段，
资源真正解码完成之后才会淡出——不存在「进度条走完但画面还没准备好」。

资源分组写在 `src/resources/manifest.js`，决定哪些进启动关键路径：

| 分组 | 时机 | 说明 |
| --- | --- | --- |
| `boot` | 启动时预加载 | 决定多久能进菜单，保持精简（当前约 2.8 MB / 49 项） |
| `music` | 进游戏后后台加载 | 校歌 5.3 MB，不阻塞启动，加载完自动接上原声轨 |
| `lazy` | 用到才加载 | 按需 |

素材增删改之后要重新生成体积表，否则进度条会用默认权重估算：

```bash
npm run sizes   # 依据 manifest 与磁盘文件写 src/resources/sizes.js
```

常用脚本：`npm run dev` 起本地服务、`npm run check` 语法检查、`npm run e2e` 端到端冒烟。
