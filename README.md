# 一中快打

广州市第一中学的校园同人格斗小游戏。纯 Canvas 实现，打开网页就能玩。

15 名角色分布在 10 列 × 4 行的学号座位上，支持双人对战与人机对战。角色由动作帧和真人照片头像组合而成，背景是校园实拍，BGM 是校歌《奉献美好给未来》。

## 玩法

- **人机对战**（菜单第一项）：1P 选好角色后，CPU 自动摇人应战。
- **双人对战**（菜单第二项）：同一台电脑，1P 与 2P 各选一名角色开打。
- **胜负**：99 秒内把对方血量打空即获胜；时间到则剩余血量多的一方获胜。
- **战斗**：靠近后攻击，命中会掉血并产生连击；防御可减伤，跳跃能躲开攻击。
- 每个角色有速度、均衡、力量、防御四种体型，手感与伤害各不相同。

## 操作

| 动作 | 1P | 2P |
| --- | --- | --- |
| 左右移动 | `A` / `D` | `←` / `→` |
| 跳跃 | `W` | `↑` |
| 攻击 | `J` | `Enter`（或小键盘 1 / 句号） |
| 防御 | `K` | 右 `Shift`（或小键盘 2 / 逗号） |

菜单用 `W` / `S` 选择、`Enter` 确认；`M` 静音；战斗中 `Esc` 或 `P` 暂停。
